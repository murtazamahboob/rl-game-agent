# RL Game Agent — Double DQN Learns to Play Neon Catch

A **Double DQN reinforcement-learning agent that learns to play Neon Catch**, an original falling-objects arcade game — built from scratch in **pure NumPy**, no PyTorch, no TensorFlow, no Gym. The agent starts knowing nothing and, over 800 episodes, goes from flailing to catching ~24 orbs a game while almost never touching a bomb.

**Verified result (deterministic, reproduced in a fresh venv): first-100-episode mean reward −6.08 → final-100 +14.86. Greedy agent beats a random policy 18.15 to −7.48** (20 episodes each, same seeds). 15/15 tests pass.

## Why this project is different

- **The game is original, not CartPole.** Neon Catch is a 10×8 grid arcade game designed for this project: orbs (+1) and bombs (−1) fall while a catcher slides along the floor, and missed orbs cost −0.2 — so the agent must learn to chase *and* to dodge at the same time.
- **A curriculum, not a fixed level.** Difficulty ramps 0 → 1 across training: the bomb spawn rate rises from 16% to 36% as the agent improves, so it keeps learning instead of plateauing on an easy level.
- **Double DQN, hand-written.** The Q-network (12 → 64 → 64 → 3, 5,187 parameters) is a NumPy MLP with backprop and Adam written from scratch. The online net picks the next action, the target net values it — cutting the over-optimism of vanilla DQN. Experience replay (5,000 transitions) included.
- **You can play it yourself.** `python examples/play.py` lets you play Neon Catch with `a` / `d` — then watch the trained agent beat your score.
- **It comes with the receipts.** Training curve, a 121-frame GIF of a greedy episode, and a full demo report are generated by the demo — see `outputs/`.

## Installation

```bash
git clone https://github.com/murtazamahboob/rl-game-agent.git
cd rl-game-agent
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
# Full demo: train 800 episodes, evaluate vs random, write report + curve + GIF
python examples/demo.py
# -> outputs/demo_report.md, outputs/training_curve.png,
#    outputs/greedy_episode.gif, outputs/model.npz

# Train only, save the model
gameagent train --episodes 800 --out outputs/model.npz

# Evaluate a saved model against a random policy
gameagent eval --model outputs/model.npz

# Play Neon Catch yourself (a = left, d = right, Enter = stay, q = quit)
python examples/play.py
```

## How it works

```
State (12 numbers)          Q-network (NumPy MLP)          Action
┌──────────────────┐        ┌───────────────────┐        ┌────────┐
│ agent x, orbs,   │  ───▶  │ 12 → 64 → 64 → 3  │  ───▶  │ left / │
│ bombs, step, and │        │ ReLU, He init,    │        │ stay / │
│ dx/dy/kind of    │        │ Adam, Double DQN  │        │ right  │
│ 3 nearest falls  │        │ + replay buffer   │        │        │
└──────────────────┘        └───────────────────┘        └────────┘
```

- **Environment** (`src/gameagent/env.py`): Neon Catch — 10×8 grid, 120 steps/episode, seeded and deterministic.
- **Network** (`src/gameagent/nn.py`): MLP with ReLU, backprop and Adam, from scratch in NumPy.
- **Agent** (`src/gameagent/dqn.py`): Double DQN, epsilon-greedy (1.0 → 0.05), target network synced every 25 episodes.
- **Training** (`src/gameagent/train.py`): curriculum difficulty, greedy evaluation vs a random baseline on identical seeds.
- **Visuals** (`src/gameagent/render.py`): matplotlib training curve + Pillow GIF of a greedy episode.

## Tests

```bash
pip install -r requirements.txt
python -m pytest tests/ -q
# 15 passed
```

Tests cover the environment (determinism, orb/bomb rewards, episode end, difficulty, rendering), the network (shapes, save/load, loss falls under training) and the agent (replay buffer, greedy action, finite TD loss, epsilon decay, **learning actually happens** — final-100 reward beats first-100, and the trained agent beats random on the same seeds).
